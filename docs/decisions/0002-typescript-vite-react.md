# 0002: TypeScript + Vite + React

**Status**: Proposed | **Date**: _TBD_

## Context
Chosen language: JavaScript/TypeScript. The UI has interactive state (modes, dialogs, drag and drop, toasts, a live list). The code will be generated by an AI agent, so a widely used stack with good test tooling helps.

## Decision
TypeScript (strict), Vite for build/dev, React for UI. Vitest + Testing Library for unit/component tests, Playwright for end-to-end.

## Alternatives considered
- **Vanilla TypeScript**: fewest dependencies, but state handling for modes/dialogs/list gets messy quickly.
- **Svelte / Preact**: smaller, fine choices; React chosen for the largest ecosystem and easiest reuse in the ERP later.

## Consequences
React + ReactDOM become dependencies. Drag and drop is implemented with pointer events (no drag library) unless a plan justifies one.
